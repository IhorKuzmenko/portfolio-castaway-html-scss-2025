# Castaway — Podcast Landing Page

Castaway is a responsive one-page website dedicated to podcasts and audio content.

The project was built using HTML5 and SCSS, with a focus on clean design, semantic markup, responsive layouts, and a consistent user experience across different screen sizes.

## 📱 Responsive Design

The website is adapted for different screen sizes:

| Device       | Screen Width     |
| ------------ | ---------------- |
| Small Mobile | 320px – 374px    |
| Mobile       | 375px – 767px    |
| Tablet       | 768px – 1023px   |
| Large Tablet | 1024px – 1439px  |
| Desktop      | 1440px and above |

The layout adjusts automatically to provide a comfortable viewing experience on different devices.

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/IhorKuzmenko/portfolio-castaway-html-scss-2025.git
   ```

2. Open the project folder:

   ```bash
   cd portfolio-castaway-html-scss-2025
   ```

3. Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.

To modify the styles, compile the SCSS source files into CSS using Sass.
